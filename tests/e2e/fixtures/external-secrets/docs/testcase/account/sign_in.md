# Sign in and create a note

## Title

Signing in and creating a note

## Precondition

An account exists for the address in the project's test variables.

## Steps

1. Open the sign-in page
2. Enter the account's email address
3. Enter the account's password and submit
4. Create a note with a unique title
5. Confirm the note appears in the list

## Expected

- The note appears at the top of the list

## Cleanup

1. Delete the created note

- The note is no longer in the list
